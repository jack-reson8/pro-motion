आज के ज़्यादातर "AI वीडियो" या तो टेम्पलेट होते हैं (3D फ़ोन + App Store बैज) या जनरेट किए गए क्लिप, जिन्हें आप डायरेक्ट नहीं कर सकते। Pro Motion तीसरा रास्ता लेता है: **पहले संगीत को मार्केटिंग एसेट की तरह प्लान किया जाता है, फिर Claude फ़िल्म को कोड के रूप में लिखता है** — कैनवस पर एक डिटरमिनिस्टिक `render(t)`। इसलिए हर हिट संगीत की 16वीं नोट तक सटीक बैठती है, हर ट्रांज़िशन डिज़ाइन किया हुआ होता है, और किसी भी शॉट को टाइमस्टैम्प के हिसाब से बदलकर सेकंडों में दोबारा रेंडर किया जा सकता है।

यह उस असली प्रोजेक्ट से निकली पद्धति है जिसमें करीब 10 राउंड तक "यह PowerPoint जैसा लग रहा है", "मटीरियल भद्दा है", "टेक्स्ट ऊपर तैर रहा है", "मैंने स्टाइलाइज़्ड कहा था, पॉप आर्ट नहीं" जैसी बातें सुनने के बाद ही कट मंज़ूर हुए। **फ़र्क़ पद्धति ने डाला, इसलिए यह स्किल पद्धति को ही समेटती है।**

## यह क्या करता है

| चरण | Claude क्या करता है |
|---|---|
| 1 · ब्रीफ़ | प्रोडक्ट, ऑडियंस, बाज़ार, संगीत, रेशियो और फ़िल्म का प्रकार तय करता है — सवालों की झड़ी लगाने के बजाय डिफ़ॉल्ट खुद चुनता है |
| 1b · कैंपेन + ऑडियो | `campaign.md` वर्कशीट: 12 अपरंपरागत मार्केटिंग लीवर (माध्यम का "ख़राब" हो जाना, पड़ोसी बिलबोर्ड से संवाद, पाबंदी को ही मज़ाक बना देना, बेतुका मैस्कॉट, बड़े पैमाने पर निजी जवाब, UGC सेना, FOOH…) से छह स्टंट आइडिया, स्कोर करके एक का चुनाव। फिर कैंपेन का केंद्र (सच · तनाव · मैकेनिक · चैनल), सोनिक लोगो और हुक वाला ऑडियो प्लान, एक सटीक Suno/Udio प्रॉम्प्ट, और अंत में `audio_post.py` से बीट पर बैठने वाले SFX, स्टटर, लूप और लाउडनेस |
| 2 · संगीत | `analyze_music.py` → टेम्पो, बीट ग्रिड, ऑनसेट, लो/हाई हिट, और ग्रिड खिंचा हुआ स्पेक्ट्रोग्राम। स्पेक्ट्रोग्राम ही एडिट है |
| 3 · रिसर्च | आधिकारिक अपलोड ढूँढता है, yt-dlp (बिना ब्राउज़र) से 24 फ़्रेम की **कॉन्टैक्ट शीट** निकालता है, और हर रेफ़रेंस के लिए एक **टेक्नीक शीट** लिखता है |
| 4 · दिशा | नाम वाली तकनीकों से **तीन साफ़-साफ़ अलग स्टाइल फ़्रेम** — कुछ भी एनिमेट होने से पहले आप चुनते हैं |
| 5 · कहानी | एक **नायक** जो हर दृश्य में रूप बदलता है; हर फ़ीचर संगीत की किसी घटना पर खुद अभिनय करता है; हर ट्रांज़िशन डिज़ाइन किया हुआ; टेक्स्ट खुद एनिमेशन है; अंत में सब कुछ लोगो में बदल जाता है |
| 6 · बिल्ड | `motion-lib.js`: ईज़िंग और स्प्रिंग, स्क्वैश और स्ट्रेच, ऑनसेट से चलने वाला बीट कैमरा, 12-fps डूडल लाइन बॉइल, कलम से लिखा जाता टेक्स्ट, मेटाबॉल, हाफ़टोन, स्ट्राइप, 3D कार्ड रिंग, स्टिकर आउटलाइन, सब्जेक्ट कटआउट (macOS Vision), बहुभाषी स्विच — साथ में AE / Blender / एनिमे तकनीकों के 40+ डिटरमिनिस्टिक canvas रूप: कर्ल-नॉइज़ पार्टिकल, लोगो में जुड़ते पार्टिकल, Saber ग्लो, शाइन, व्हिप पैन, आइरिस, स्याही का फैलाव, बिखराव, ज़ूम-थ्रू, कागज़ फाड़ना, मॉर्फ़, मांगा पैनल, अनंत ज़ूम, RGB स्प्लिट, ग्लिच, डिदर, ASCII, रिसो, कट पेपर, टून शेडिंग, हैचिंग, वॉटरकलर, स्लिट-स्कैन, इको, स्पीड रैंप। `fx-demo.html` हर इफ़ेक्ट को एक सेकंड के लिए दिखाता है |

## इंस्टॉल करें

**Claude Code प्लगइन के रूप में (अनुशंसित)**

सेशन में: `/plugin install pro-motion --marketplace jack-reson8/pro-motion` — या शेल से:

```bash
claude plugin marketplace add jack-reson8/pro-motion
claude plugin install pro-motion@pro-motion
```

**सामान्य स्किल के रूप में**

```bash
git clone https://github.com/jack-reson8/pro-motion
cp -R pro-motion/plugins/pro-motion/skills/pro-motion ~/.claude/skills/
```

ज़रूरतें: Node 18+, `numpy scipy matplotlib` के साथ Python 3, Chrome/Chromium (अपने-आप पता लग जाता है, या `CHROME=/path` दें)। सब्जेक्ट कटआउट के लिए macOS 14+ चाहिए। बाकी सब कुछ `scripts/setup.sh` हर प्रोजेक्ट में इंस्टॉल कर देता है।

**Codex** (CLI या ChatGPT डेस्कटॉप ऐप):

```bash
codex plugin marketplace add jack-reson8/pro-motion
codex plugin add pro-motion@pro-motion
```

या `plugins/pro-motion/skills/pro-motion` को `~/.codex/skills/` में कॉपी करें। यह स्किल खुले [Agent Skills](https://agentskills.io) मानक का पालन करती है, इसलिए Claude Code, Codex और SKILL.md पढ़ने वाले किसी भी एजेंट में चलती है।

**अन्य एजेंट** (Cursor, Gemini CLI, GitHub Copilot और skills CLI द्वारा समर्थित अन्य एजेंट):

```bash
npx skills add jack-reson8/pro-motion
```

## इस्तेमाल कैसे करें

बस ट्रैक के साथ माँगिए:

> मेरे फ़ोटो ऐप के लिए 20 सेकंड का लॉन्च वीडियो बनाओ, `~/Downloads/track.mp3` पर कटा हुआ। वर्टिकल, अंग्रेज़ी मास्टर और जापानी व कोरियाई कट भी।

> 用这首歌给我的品牌做一支强烈风格化的品牌片，先给我三个风格方向的风格帧。

> 8–10 सेकंड वाला हिस्सा स्लाइडशो जैसा लग रहा है — वहाँ के ट्रांज़िशन दोबारा डिज़ाइन करो।

Claude स्किल की प्रक्रिया पर चलता है: संगीत का विश्लेषण, कॉन्टैक्ट शीट से रिसर्च, स्टाइल फ़्रेम दिखाना, `shotmap.md` लिखना, `film.js` बनाना, `out/*.mp4` रेंडर करना, फ़्रेम शीट जाँचना और नतीजा खोलकर दिखाना।

## सिद्धांत (संक्षेप में)

1. **संगीत ही एडिट है।** स्पेक्ट्रोग्राम पढ़िए; हर मूवमेंट को मैप किए गए इवेंट पर उतारिए।
2. **असली फ़्रेम देखिए, याददाश्त से डिज़ाइन मत कीजिए।**
3. **स्टाइल फ़्रेम से दिशा चुनिए,** पहले ख़याल या कोड करने में सबसे आसान चीज़ से नहीं।
4. **एक नायक, अभिनय करते इफ़ेक्ट, डिज़ाइन किए हुए ट्रांज़िशन** — वरना वह PowerPoint जैसा लगेगा।
5. **टेक्स्ट एनिमेशन है।** न लोअर-थर्ड, न चिप, न बॉक्स।
6. **भद्दा मटीरियल, भद्दी फ़िल्म।** असली, ताज़ा, लाइसेंस-सुरक्षित मटीरियल लीजिए — या खाली जगह छोड़ दीजिए।
7. **सेकंडों में रेंडर, एक कॉन्टैक्ट शीट से जाँच, डिलीवरी।** आगे टाइमस्टैम्प के हिसाब से सुधार कीजिए।
